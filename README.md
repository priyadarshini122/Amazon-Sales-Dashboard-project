# Amazon Sales Analysis Dashboard

## Project Overview
This project analyzes Amazon sales data using Power BI to understand sales performance, profitability, product categories, customer segments, and regional trends.

## Tools Used
- Power BI
- Data Visualization
- Data Analysis

## Dashboard Features
- Total Sales, Quantity, Profit, and Shipping Cost KPIs
- Sales by Product Category
- Monthly and Yearly Sales Trends
- Sales and Profit by Customer Segment
- Revenue and Profit by Category and Subcategory
- Average Discount by Subcategory
- Sales and Profit by Region, State, and City
- Customer Geographic Distribution

## Key Objectives
- Identify top-performing product categories.
- Analyze sales and profit trends.
- Compare customer segments and geographic regions.
- Support data-driven business decisions.
